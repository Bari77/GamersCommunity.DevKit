Le catalogue est une simple liste d'objets, sans classe ni enregistrement dynamique. Il se construit donc là où l'application dispose de son contexte, par exemple pour traduire les libellés ou masquer un type selon les droits.

Entrée de catalogue

Champs de réglage

La modale de réglages est générée à partir de fields : il n'y a rien à écrire pour un widget dont les réglages tiennent en quelques champs simples. Deux formes existent.

Champ simple

Champ répétable

Un champ de type list répète un groupe de champs, ce qui permet à un widget de porter un nombre libre d'entrées — des liens, des équipiers, des vidéos.

Réglages sur mesure

Quand les champs générés ne suffisent pas, la directive gcWidgetSettings ajoute votre propre interface sous les champs générés, pour un type donné. Elle reçoit le même contexte que le gabarit de rendu. Réservez-la aux paramètres d'instance, pas au contenu backend : celui-ci s'édite dans le widget via gcWidgetEditable , voir Concepts .

Titre du widget

Un champ de titre est ajouté à tous les widgets sans avoir à le déclarer. Il est stocké dans les réglages sous la clé exportée WIDGET_TITLE_KEY , et un titre vide masque l'en-tête du widget.
